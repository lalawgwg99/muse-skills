# digest-link-verify

Requires：可上網的搜尋與開頁工具；不需要任何 key。

來源：2026-10-29～10-31 動區早晚報實戰長出來的流程——排程 worker 連續三天只回主題摘要、不含逐則內文與連結，主對話逐篇核實重建後才交付。

## When to Use
- 別人（排程 worker、協作 agent、摘要工具）只給了「主題摘要」，缺逐則內文與原文連結，而你要把摘要交付給使用者時。
- 交付新聞早晚報、市場快訊、任何「標題＋重點＋連結」格式的整理時。
- 不用在：你自己親自讀過原文的整理；不需要附連結的內部筆記。

## Procedure
1. 拿 worker 的每一則主題，去來源站（或來源站站內搜尋）找對應原文，逐篇核對：標題、關鍵數字、發生時間三者都要對上。
2. 連結只能用工具回傳或來源站顯示的原網址，逐字照抄。絕對不拼網址、不猜 slug、不把舊文連結當新文。
3. 來源站找不到原文時，改附可查證的外部相關報導，並在連結前標註「相關報導」，不要假裝它是來源站原文。
4. 數字以原文為準；價格類數字以即時報價為準，不要沿用摘要裡的舊數字。
5. 未經證實的消息標「未證實」；沒有重大新聞就明說「無重大消息」，不要硬湊。
6. 交付後把「哪幾則用了替代連結」記入當日日誌，下次同一來源缺失時有跡可循。

## Pitfalls
- worker 摘要不可直接照發：摘要的數字與連結缺失率很高，照發等於把未核實的東西掛上你的名字。
- 搜尋結果的舊聞不要當新文：同一主題常有舊文（例如 CFTC 10/12 的舊提案 vs 10/30 的新發言），要看發布時間，不看標題相似度。
- 同一事件在一天內會出多篇追蹤文（例如幣安駭案的公告 #1、#2 與懶人包持續更新），取最新一篇的時間點為準，並註明更新時間。
- 替代連結不是降級：標註清楚的相關報導，比臆造的來源連結誠實，也比缺連結好。

## Verification
- 交付前逐條檢查：每一則都有可點開的連結；連結點開後的標題與你寫的標題一致；所有數字能在連結頁面或即時報價中找到。
- 檢查替代連結都有「相關報導」標註，且沒有任何一則的連結是你拼出來的。
